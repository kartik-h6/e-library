# Security policy

## Scope
This repository currently proposes a public static library. Expectations change if accounts, uploads, or private maintainer tools are added.

## Reporting
Do not publish secrets, personal data, or exploit details in a public issue. A private reporting contact should be added once a verified maintainer-controlled channel is configured. Until then, public issues are for non-sensitive defects only.

## Rules
- Never commit secrets or private student information.
- Never rely on client-side checks as authorization.
- Review redistribution permissions before publishing files.
- Remove unsafe/misleading links and document significant corrections.
