Contact & corrections

Found a broken link, a wrong unit title, or a subject that should be listed? Tell us — corrections are welcome.

Report a correction

  • Open an issue in the project's GitHub repository (preferred for non-sensitive items).
  • For anything sensitive, use a private channel to the maintainer rather than a public issue.

Contribute material

Have notes, a previous question paper, or a lab manual for a subject? Send it through either channel above and it will be reviewed before it appears.

We can publish: your own notes, openly licensed material, and links to lawful sources.

We can't publish: copyrighted textbooks, paid coaching material, restricted institutional files, or personal data.

This is a static site — there is no shared upload database and no login, so a form here could not store submissions. Please use the issue tracker or email, which reach a maintainer.

See CONTRIBUTING in the repository for the full guide.

Do not post credentials or personal data in public issues.
