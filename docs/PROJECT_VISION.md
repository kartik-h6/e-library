# Project vision

## Purpose
Make academic learning resources easier for RIPER students to discover and use through an organized, mobile-friendly library.

## Problem
A folder of PDFs is not enough: students need a predictable path from programme and semester to subject, unit, and resource, plus metadata to judge relevance.

## Intended users
- **Students:** find and open resources on mobile or desktop.
- **Faculty/resource reviewers:** validate academic relevance and accuracy.
- **Maintainers:** organize records, check links, and keep content current.
- **Contributors:** suggest resources with source and rights information.

These proposed roles do not imply that authentication or an admin backend already exists.

## Principles
- Clarity before visual complexity.
- Curriculum accuracy before breadth.
- Stable, shareable URLs.
- Low-bandwidth and keyboard-friendly access.
- Transparent sourcing and licensing.
- Privacy by default and minimal data collection.
- Technology supports educators and students; it does not replace academic judgment.

## Success indicators
After launch, consider measuring successful resource opens, search-to-resource success, broken-link rate, metadata completeness, accessibility findings, and usability-test time to find a resource. Avoid collecting identifiable student activity unless there is an approved need and clear notice.
