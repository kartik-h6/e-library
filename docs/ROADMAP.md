## Stage 2 — Content quality
- [ ] Add only verified syllabus entries and rights-cleared resources.
- [ ] Add review metadata and broken-link checking.

## Stage 3 — Expansion only if useful
- [ ] Decide if shared submissions or maintainer tools are needed.
- [ ] If needed, select backend, auth, storage, privacy notices, and access controls.
- [ ] Consider offline/PWA and multilingual support after usability tests.

## Launch definition
A student can reliably find a curriculum-mapped resource through a direct, searchable path; metadata is verified; rights are clear; navigation is accessible; no insecure admin or private data is exposed; and the deployed version is smoke-tested.
