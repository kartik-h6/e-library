# Accessibility and user experience

## Design targets
- Mobile-first responsive layout for student phones.
- Clear hierarchy: semester → subject → unit → resource.
- Labels with meaning; no icon-only controls without accessible names.
- Consistent breadcrumbs and back-navigation patterns.
- Fast initial render and minimal unnecessary network requests.

## Checklist
- Semantic header, nav, main, section, and footer landmarks.
- Logical heading order and meaningful page titles.
- Full keyboard operation and visible focus.
- Labels for search and form controls.
- Sufficient contrast; do not rely on colour alone.
- Useful alt text for meaningful images; empty alt for decorative assets.
- Announce result counts/status messages where appropriate.
- Respect reduced-motion preferences.
- Descriptive links and file type/size where known.
- Test zoom/reflow, keyboard navigation, and at least one screen-reader workflow.

## Search
Search published metadata, not private or unsupported file contents. Filters should be optional and clearable. Empty states should explain how to broaden a query or report a missing resource.
